## Cardinal rules (please respect)

- **No claims you can't back with a screenshot.** Numbers in these drafts (~80 tools, broker list, etc.) match what `tools/list` actually returns and what's on the dashboard. Don't change them upward.
- **Don't promise financial outcomes.** Atlas is a tool layer. Performance, P&L, "edge" claims are not okay.
- **Disclose that orders touch real brokers.** The preview-first safety model is part of the pitch — don't bury it.
- **Reddit hates marketing.** The Reddit drafts are written as "I built X" first-person, with the link buried at the bottom. Keep it that way.
- **One post per subreddit per week max.** Anything more reads as spam and will get the account shadow-banned.

## Differentiation, in one paragraph

> Most MCP servers expose generic tools — file systems, shells, code editors. Atlas is a **domain-specific** MCP for markets and trading. ~80 tools cover quotes, options chains and Greeks, ~Greek exposure heatmaps (DEX/GEX/VEX/TEX), real broker account access (Alpaca, Webull, Tradier, Public, Schwab and more — *not* Robinhood/Fidelity), preview-first order placement, persistent workflow triggers, and Discord/SMS/Telegram alerts. It's hosted — agents connect via streamable-HTTP with one Bearer key from your dashboard. No code to compile, no daemon to babysit.

Use that paragraph (verbatim or paraphrased) as the core value prop in any post.
